# KAFV 인터랙티브 AI 통합 특강교재

**KAFV All-in-One Interactive Lecture | Ver 1.1**

한국어촌가치연구소(KAFV)에서 개발한 인터랙티브 AI 교육 플랫폼입니다.

다중 문서 강의실, 웹앱 개발환경 이해, AI 웹앱 제작 실습을 하나의 통합교재로 제공합니다.

본 교육자료는 대학 강의, 학술 연구, 개인 학습 및 비영리 교육을 목적으로 공개합니다.


## 📚 교육과정 구성

### 0단계 | 인터랙티브 다중 문서 강의실

**Interactive Multi-Document Classroom | Ver 1.2**

특정 강의자료에 종속되지 않는 범용 인터랙티브 강의실입니다.

주요 기능:
- 여러 PDF 파일 불러오기 및 목록 관리
- PDF 1개·2개·3개 분할 비교
- 선택 문서 단독 확대 및 비교 화면 복귀
- PDF 별도 창 열기
- 드래그 앤 드롭 파일 불러오기
- PPT·Word 파일 선택 및 다운로드
- GitHub에 공개된 온라인 PDF 강의자료 목록 연동
- ChatGPT·Gemini·공공데이터포털·웹앱 제작 마법사 QR 접속

개인 PC에서 선택한 파일은 자동으로 서버에 업로드되지 않습니다.

PPT·Word의 편집 및 원본 실행 기능은 사용자의 PC에 설치된 해당 프로그램을 이용합니다.

### 1단계 | GitHub·공공 API·Cloudflare 이해

**Web Development Environment & Workflow | Ver 1.0**

실제 개발 화면을 활용하여 웹앱의 제작·저장·공개 및 데이터 연결 과정을 이해합니다.

주요 교육 내용:
- GitHub 계정과 Repository
- GitHub Pages를 활용한 웹앱 공개
- 공공데이터포털 및 Open API
- Cloudflare Workers의 역할
- 실제 화면 기반 16개 학습 절차
- 공식 사이트 바로가기 및 QR
- ChatGPT 질문문과 학습 도움말

### 2단계 | 웹앱 제작 마법사와 AI 앱 설계

**No-Code Web App Design & Practice | Ver 1.3**

코딩 경험이 없는 학습자도 UI·UX 구성요소를 이해하고 웹앱을 직접 설계하는 실습 과정입니다.

주요 교육 내용:
- 9개 시작 틀과 웹앱 유형 이해
- 34개 UI·UX 부품의 역할
- 59개 학습 화면
- 미니 플레이를 통한 기능 체험
- KAFV 웹앱 제작 마법사 실행
- 화면 구성과 기능 조립
- AI에게 전달할 웹앱 요구명세서 작성

교육의 핵심은 단순히 웹앱 하나를 만드는 것이 아니라, **AI에게 원하는 앱의 구조와 기능을 정확하게 설명하고 그 결과를 검증할 수 있는 능력을 기르는 것**입니다.

## Cloudflare R2 비공개 PDF 열람 개편

이 버전에서는 온라인 PDF 원본을 GitHub 저장소에 포함하지 않습니다. PDF 2개를 비공개 R2 버킷에 업로드하고, Worker를 통해 문서 목록과 PDF 바이트를 중계합니다. `pdf-config.js`에 Worker URL을 등록하세요.

**PDF 다운로드 UI는 제거**했습니다. 화면 캡처는 허용됩니다. 웹 브라우저는 열람을 위해 PDF 파일 바이트를 수신하므로 개발자도구·네트워크 기록 등을 통한 완전한 복제 차단은 보장할 수 없습니다. PDF.js는 외부 CDN을 사용하므로 인터넷 연결이 필요합니다.

PDF 저장소의 공개 GitHub `pdf/` 폴더에 기존 PDF가 남아 있다면 반드시 삭제하고 배포를 갱신해야 원본에 대한 공개 직접 URL을 차단할 수 있습니다.
