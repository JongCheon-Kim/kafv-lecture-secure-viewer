# KAFV 인터랙티브 특강교재 · PWA PC PDF 열람 개선 + 시작 화면

## 배포
ZIP의 `index.html`, `sw.js`, `manifest.webmanifest`, `assets/` 폴더를 기존 GitHub Pages 저장소 루트에 **같은 경로로 덮어쓰기**합니다. `pdf-config.js`, `pdf-viewer.html`, 기존 README 등 이미 있는 파일은 삭제하지 않습니다.

## 변경 사항
- 0단계 PC: 플러그인 의존 `blob:` PDF iframe 대신 PDF.js 캔버스 뷰어로 표시. 스크롤, 페이지 이동, 확대/축소, 전체화면 유지
- 0단계 모바일: 기존 승인 PDF.js 한 페이지 뷰어 코드를 유지
- 설치된 Android/PC PWA: 운영체제 스플래시(아이콘) → 승인 대문 약 1.9초 → 통합 첫 화면
- 일반 브라우저/바로가기: HTML 아이콘 화면 약 0.75초 → 승인 대문 약 1.9초 → 통합 첫 화면
- iOS PWA는 중복 방지를 위해 OS 시작 화면을 우선하며 별도 HTML 대문을 생략
- 기존 1·2단계 교재, 온라인 PDF Worker 주소, 실습 QR, PWA 아이콘/이미지 원본 변경 없음

## 유의
- PDF.js는 기존 모바일 성공본과 같은 cdnjs 라이브러리를 사용하므로 인터넷 연결이 필요합니다.
- GitHub Pages가 업데이트된 뒤 설치 앱을 완전히 종료하고 재실행하십시오. 오래된 서비스 워커가 남아 있으면 업데이트 뒤 앱을 한 번 더 재시작하십시오.
- 앱 스플래시(운영체제 제어) 시간은 브라우저·OS에 따라 달라집니다.
- PC/모바일 PDF 실제 Cloudflare R2 자료의 로딩, 전체 페이지 이동, 스플래시 순서를 배포 후 한 번씩 확인하십시오.
- 브라우저 바로가기 실행을 기술적으로 항상 구별할 수 없으므로 **새 브라우저 방문**에도 대문이 한 번 표시됩니다. 새로고침 및 1·2단계 직접 링크는 시작 연출을 생략합니다.

## 검수 범위
소스 원본(1·2단계) 불변 및 테스트용 PDF로 PC/모바일 렌더링, 전체화면, 단계 이동, 시작 화면 상태를 확인했습니다. 실서비스의 설치형 앱 동작은 최종 확인이 필요합니다.
